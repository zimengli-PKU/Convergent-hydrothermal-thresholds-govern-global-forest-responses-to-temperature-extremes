# Convergent-hydrothermal-thresholds-govern-global-forest-responses-to-temperature-extremes
Code for main analyses in Article "Convergent hydrothermal thresholds govern global forest responses to temperature extremes"

File descriptions:
1. calculate_dRWI.m : to calculate ΔRWI values using standardized tree-ring chronologies.
2. multi-model comparison.R : comparison of the performance between linear, quadratic, linear-plateau and quadratic-plateau regressions
3. Comparison among OLS, spatial-resampled OLS and LMM.R : test the sensitivity to spatial imbalance and species
4. dRisk_and_attribution.m : calculate Risk changes under SSP245and SSP585, as well as attibution of ΔRisk to MAT/MAP chnages.
